# PKIG — Aplikacja Pracownika

Aplikacja PWA do ewidencji czasu pracy dla pracowników PKIG.

## Hosting na GitHub Pages
1. Utwórz nowe repozytorium (np. `pkig-pracownik`)
2. Wgraj pliki `index.html` i `manifest.json`
3. Settings → Pages → Source: `main` branch → `/root`
4. Adres: `https://TWOJA-NAZWA.github.io/pkig-pracownik/`

## Instalacja na telefonie
- **iPhone:** Safari → Udostępnij → Dodaj do ekranu głównego
- **Android:** Chrome → menu → Zainstaluj aplikację

## Konfiguracja API
URL backendu wpisany w `index.html` (zmienna `API_URL`).
Aby zmienić — edytuj linię z `const API_URL`.
